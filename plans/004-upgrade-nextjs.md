- **Priority**: P2

## Why this matters

`next@15.3.0` has multiple CVEs confirmed by `pnpm audit`: a CRITICAL RCE in the React flight protocol, HIGH middleware/proxy bypass, DoS via server components, and SSRF via WebSocket upgrades. Latest 15.x at time of writing is `15.5.20`. Staying on 15.3.0 ships known exploitable vulnerabilities to users.

## Current state

`package.json:27`: `"next": "15.3.0"`

`pnpm-workspace.yaml` currently has placeholder `allowBuilds` values that prevent `pnpm install` from completing:
```yaml
allowBuilds:
  '@firebase/util': set this to true or false
  protobufjs: set this to true or false
  sharp: set this to true or false
```
This must be fixed before running `pnpm install`.

## Scope

**In scope**: `package.json`, `pnpm-lock.yaml` (regenerated by pnpm), `pnpm-workspace.yaml`
**Out of scope**: all source files — if the upgrade requires source changes, STOP and report

## Steps

### Step 1: Fix `pnpm-workspace.yaml`

Set all three `allowBuilds` entries to `true`:
```yaml
allowBuilds:
  '@firebase/util': true
  protobufjs: true
  sharp: true
```

### Step 2: Update `next` version in `package.json`

Change `"next": "15.3.0"` to `"next": "15.5.20"`. Also update `"eslint-config-next"` to match: `"eslint-config-next": "15.5.20"`.

### Step 3: Run `pnpm install`

```
pnpm install
```

Expected: resolves and writes updated `pnpm-lock.yaml`, exit 0. If it fails due to peer dependency conflicts, STOP and report.

### Step 4: Verify

```
npx tsc --noEmit
npx next build
```

Both must exit 0. If the build fails with a Next.js-version-specific error, STOP and report the exact error.
